# P25 菜单淡入淡出（含二级菜单切换）

> 2026-10-28 23:35

## 1. 效果

| 动作 | 效果 | 时长 |
|---|---|---|
| KEY3 打开功能菜单 / KEY4 打开音乐列表 | 遮罩 + 面板 + 文字整体 0→100% 淡入 | 8 帧 ≈ 0.27s（30fps） |
| KEY4 关闭菜单 | 整体 100%→0 淡出 | 8 帧 ≈ 0.27s |
| 设置页 → IMG / VU 二级菜单（换页） | 先淡出到全黑，**看不见的瞬间换页**，再淡入 | 0.27s + 0.27s |

字幕条（底部滚动文字）与"无图片"告警**不参与**淡入淡出，始终全亮。

## 2. 实现

`osd_menu.v` 里加一个帧域的淡入淡出电平 `mfade`（0..8）：

```verilog
reg [3:0] mfade;
wire      page_chg = (r_page != page);
always @(posedge clk or posedge rst) begin
    if (rst) mfade <= 4'd0;
    else if (frame_start) begin
        if (!open || page_chg) mfade <= (mfade == 4'd0) ? 4'd0 : mfade - 4'd1;
        else                   mfade <= (mfade == 4'd8) ? 4'd8 : mfade + 4'd1;
    end
end
wire mvis = r_open | (mfade != 4'd0);      // 渲染用：淡出期间继续画
```

三个要点：

1. **渲染条件用 `mvis` 而不是 `r_open`**：`r_open` 立刻跟随按键（它只决定"要不要画"），
   所以关闭时 `r_open=0` 但 `mfade>0`，面板还要继续画出来让它淡下去。
2. **换页冻结**：`r_page/r_item` 只在 `mfade == 0` 时更新。
   这样换页的瞬间画面已经全黑，不会"半透明时内容突然换掉"；
   正常显示时 `mfade` 恒为 8，光标移动仍然逐帧跟手。
3. **透明度缩放**：

```verilog
// 整层（全屏遮罩 / 边框 / 面板 / 高亮条）
s0_base_alpha = ({4'd0, s0_base_alpha} * {4'd0, mfade}) >> 3;
// 菜单文字：跟着 mfade；字幕/告警恒为 8（新增 s0/s1/s2_tmenu 标志跟流水）
osd_alpha <= s2_tmenu ? mfade : 4'd8;
```

> ⚠️ 踩坑：第一版写成 `(s0_base_alpha * mfade) >> 3`，仿真里 alpha 只出现 0/1。
> 原因是 **Verilog 乘法结果宽度 = max(操作数宽度)**，4 位 × 4 位会先截成 4 位
> （`8*8=64` 截成 `0`），再右移就只剩最低位。必须显式补到 8 位。

## 3. 验证（`sim/tb_menu_fade.v`，新增）

单独例化 `osd_menu`，每"帧"打一拍 `(x==0,y==0)` 制造 `frame_start`，
然后把坐标停在面板内部一点读 `osd_alpha`，检查逐帧轨迹：

| 步骤 | 期望 | 实测 |
|---|---|---|
| 关闭态 | alpha=0、osd_on=0 | 0 / 0 ✓ |
| KEY3 打开 | 每帧 +1，0→8，不跳变 | 1,2,3,4,5,6,7,8 ✓ |
| KEY3 进 IMG 子菜单 | 8→0 淡出，`r_page` 在 alpha=0 那帧换成 2，再 1→8 | 8,7,6,5,4,3,2,1,0 **换页** 1,2,...,8 ✓ |
| KEY4 关闭 | 每帧 -1，8→0 | 7,6,5,4,3,2,1,0 ✓ |

`RESULT: PASS`；原 `tb_osd_demo`（48 项断言）仍 PASS，说明按键/参数链路没有被影响。
