# P17 键位重排与轮播/切图修复

> 2026-10-27 · 针对上板反馈的三类问题（键位不合手、轮播开关无效、上下键不切图）

## 1. 新的按键语义（全界面统一）

| 键 | 菜单关闭时 | 菜单打开时 |
|---|---|---|
| **KEY1** | 上一张 | 光标上移 |
| **KEY2** | 下一张 | 光标下移 |
| **KEY3** | 打开**功能菜单**（设置页） | 确认 / 进入子菜单 / 改值 |
| **KEY4** | 打开**音乐列表** | 关闭（任何页一次按键退出） |

一句话记法：**KEY1/KEY2 = 上下，KEY3 = 进，KEY4 = 退**。
"上/下"在菜单内外是同一个方向，不会出现"菜单里按上、菜单外按下"的反向感。

实现位置：

- `rtl/top_board.v`：`.key({key3, key2, key1, key4})` —— 位序 `{OK, DOWN, UP, LIST}`
- `rtl/ui/osd_menu.v`：`key_menu`(KEY4) / `key_ok`(KEY3) / `key_up`(KEY1) / `key_down`(KEY2)；
  KEY3 打开 page0（设置），KEY4 打开 page1（音乐）
- 菜单底部提示统一为 `OK SET   K4 EXIT`（原来分 SET/NEXT 两种）

## 2. 轮播三个 bug

### 现象

1. 菜单里 AUT 显示 OFF，画面仍然自己切图
2. 切屏间隔改了没反应
3. OFF 状态下改"切屏间隔"就开始切图

### 根因

计时器和开关判断散落在 `top_board.v` 的 `LD_SHOW` 里：

```verilog
if (frame_top && dbg_auto) hold_frm <= hold_frm + 1;      // 计数
...
else if (nav_next || nav_prev || (dbg_auto && (hold_frm >= hold_lim)))
```

三个隐含问题：

- `hold_frm` 只在 `dbg_auto` 为 1 时累加，但**关掉 AUT 后不清零**，
  残留计数会在下次打开（或读到一个刚好满足的阈值）时立刻触发 —— 看着像"一改档位就切"；
- `hold_lim` 直接由 `dbg_hold` 组合译码，**改档位的瞬间**就用旧计数去比新阈值，
  所以"改间隔"和"立刻切图"耦合在一起；
- 手动按键 `nav_next/nav_prev` 是**单拍脉冲**，只在 `LD_SHOW` 里判，
  落在 `LD_CLEAR/LD_ARM/LD_LOAD/转场` 里就彻底丢了 —— 这就是"按上下键不切图"。

### 修法：抽成 `nav_ctrl`（并入 `rtl/ui/key_ctrl.v`）

TD 命令行不认新增源文件，所以模块写在已有的 `key_ctrl.v` 末尾。

```
nav_ctrl(
  frame_tick, showing, auto_en, hold_sel, key_next, key_prev
  -> step, step_prev, hold_cnt
)
```

四条规则：

1. **自动必须 auto_en=1 才累计**；`!auto_en` 时 `hold_cnt` 每拍强制清零
   → OFF 状态下物理上不可能凑够阈值
2. **档位一变立刻清零**（`hold_sel != hold_d`），重新从头计时
   → 改间隔不会再"顺手切一张"
3. **每次切图（手动或自动）计数归零**，间隔从新图开始算
4. **手动按键挂起**（`pend`），等 `showing=1` 再执行
   → 加载/转场期间的按键不丢，且不会连点滚过多张（挂起只有"有/无"）

`top_board.v` 里 `LD_SHOW` 现在只有两个分支：

```verilog
if (nav_step)                ...  // 切下一张/上一张（nav_ctrl 已判好方向）
else if (dbg_scale != scale_d) ...  // 缩放档位变了，重载当前这张
```

`nav_step` 放在前面，保证"同一拍既按键又改缩放"时按键不被吞。

## 3. 验证

### `sim/tb_nav_ctrl.v`（新增，`run_nav.bat`）

直接给 `nav_ctrl` 灌帧脉冲和按键，27 项断言：

| 用例 | 期望 | 结果 |
|---|---|---|
| OFF，3s 档跑 200 帧 | 0 次切图 | ok |
| OFF，改档到 5s 再跑 200 帧 | 0 次 | ok |
| OFF，改到 30s 跑 300 帧 | 0 次，`hold_cnt` 恒 0 | ok |
| ON，5s 档 | 149 帧不切、150 帧切 1 次、方向=下一张 | ok |
| 切完重新计时 | 140 帧不切、再过 20 帧第 2 次 | ok |
| 计到 100/150 时改 8s 档 | 150 帧内不切，累计 245 帧后才切 | ok |
| 关掉 AUT | `hold_cnt`=0，300 帧不切 | ok |
| 显示中按 KEY2 / KEY1 | 各切 1 次，方向正确 | ok |
| 加载中（showing=0）按 KEY1 | 挂起不切；回到显示态切 1 次；不会重复 | ok |
| 连按两次 | 只切 1 次 | ok |
| 手动与自动同拍 | 手动优先，方向=上一张 | ok |

`RESULT: PASS`
