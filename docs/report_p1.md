# 作品名称：万象智屏

## —— 基于安路 EG4S20 的多功能智能显示广告牌

## 摘要

本作品面向多功能智能显示广告牌场景，在安路 EG4S20BG256 FPGA 上实现了一台 HDMI 智能显示终端——"万象智屏"。系统无处理器、无操作系统、无上位机，全部功能由片上硬件逻辑完成，以一张 FAT32 SD 卡作为唯一内容载体，插卡即可播放。

上电后系统自动完成 SD 卡初始化、MBR 与 BPB 解析、根目录扫描与簇链构建，把卡上的 BMP 图片与 WAV 音乐直接读入流水线，图片与音乐的数量、名称完全由卡上文件决定，无需预生成镜像。图像通路为"SD 字节流 → BMP 解码 → 缩放适配 → 异步 FIFO → 帧缓存 → SDRAM 双缓冲 → 4:3 上采样读出 → 转场 → OSD 叠加 → TMDS 发送"，以 1280×720@30 Hz 输出；音频采样直接嵌入 HDMI 数据岛，音画同源、一根线输出。

受 2 MB 可用 SDRAM 地址空间的限制，作品采用 960×540/RGB565 双缓冲（每帧 1 036 800 B），读侧以"精确 3/4 抽取"无插值铺满 720p，在容量、带宽与画质之间取得平衡。在此基础上实现了四种转场、任意分辨率缩放适配、滚动字幕、Goertzel 32 段频谱（条形/圆形）、四页带淡入淡出的 OSD 菜单与六位数码管现场自诊断。

工程上的关键突破是"读图慢"与"进度条反复"两个顽症。逐层定位后发现瓶颈不在 SD 卡，而在帧缓存的写窗口——写 FIFO 只在每帧帧首 16 行排空，读图源被节流到每帧约 256 像素。把被同一信号绑死的"写侧出队"与"帧首复位"拆开后，单张切图从近 30 s 降至 1.3 s；再配合全链路超时与一次自愈重挂载，彻底消除了 SPI 总线死锁与进度重走。

系统占用 LUT 14 888/19 600（76.0%）、寄存器 8 699、BRAM 31 块，默认布线脚本下无违例，clk_pix 同域余量 +1.3 ns 以上，可长时间连续轮播。

**关键词**：FPGA；HDMI；数字标牌；FAT32；帧缓存；音视频融合

## 第一部分  作品概述

### 1.1 功能与特性

**内容管理**：以 FAT32 SD 卡为唯一内容源，根目录下的 BMP 与 WAV 自动识别，数量与文件名自适应；支持 8.3 短名，插卡即用。

**图片浏览**：轮播与手动双模式。轮播停留时间 1~99 s 可调；非轮播时用上下键逐张切换，进度实时显示在数码管上，用户能确认"指令已收到"。

**转场效果**：淡入淡出、左右滑动、擦除、硬切四种，可在二级菜单随时更换。

**缩放适配**：任意分辨率均能不变形适配 16:9，留边以原图模糊压暗铺满。

**图层叠加**：底部滚动字幕与"无图片"告警为独立图层，与菜单、频谱互不干扰，字幕可单独开关。

**音频与可视化**：内置音阶用于无卡演示，插卡后播放卡上 WAV；32 段实时频谱提供条形与圆形中央式两种样式。

**交互界面**：四页 OSD 菜单，字符由坐标实时生成，开关与进出二级菜单均有淡入淡出。

**现场自诊断**：六位数码管显示"加载次数 | 出错状态 | 图片数 | 音乐数"，加载中前两位变为 00~99 进度，出错可直接定位到模块。

### 1.2 应用领域

**主场景：多功能智能显示广告牌。** 门店海报机、展会展台、博物馆图文屏的共同痛点有三：换内容要带笔记本、装厂商软件；常年通电无人值守；切换要柔和不能突兀。万象智屏一次解决——换内容只是"把文件拷进 SD 卡"，上电 2 s 出画面，全程无操作系统；长时间运行有超时与自愈兜底；默认淡入淡出不做硬切。一机多能是它与普通播放盒的区别：轮播与四种转场、任意分辨率自适应、滚动标语字幕、背景音乐与 32 段频谱装饰、四页菜单现场调参，全部在一块 FPGA 内完成。

**家庭相框与小型展陈。** 同一套硬件换上生活照与轻音乐，就是插电即用的音乐相框；换一张卡即换一整套内容。

**应急信息发布与车载显示。** 应急场景要求上电即显示、不依赖网络与主机；纯硬件的确定性时序意味着只要供电和屏正常，画面必然输出。车载看重启动速度与抗振动，无硬盘无系统的方案有天然优势。

**教育与工业 HMI。** 从 SD 协议、FAT32 到帧缓存与跨时钟域，一条链路完整打通，可拆解讲授。

### 1.3 主要技术特点

**纯硬件流水线。** 从 SD 命令时序到 TMDS 编码全为 RTL 逻辑，无取指、中断与调度，像素延迟确定，无软件栈的偶发卡顿。

**三时钟域、两级异步 FIFO。** 25 MHz / 125 MHz / 37.5 MHz 独立运行，靠异步 FIFO 与打拍电平衔接。跨域关键不在 FIFO，而在"何时允许读"——写读两侧复位语义必须分离。

**由带宽预算反向驱动架构。** 先算出 SDRAM 实测读带宽（7.5 M 字/s）与 720p60 行内需求（14.4 M 字/s）的差距，才决定像素时钟 37.5 MHz 与 960×540 双缓冲。架构不是想好了再算，而是算完才定。

**全链路超时与一次自愈。** 命令 21 ms、收数 21 ms、扇区 21 ms、顶层 3.4 s，每个等待都有退路。超时后复位 SD 段重挂载再试一次，第二次失败才保留旧画面收工，绝不黑屏。

**参数帧同步提交。** 亮度、对比度、缩放、音量与各开关先暂存，帧首统一提交，避免半屏新旧参数撕裂。

### 1.5 主要创新点

1. **无镜像 FAT32 直读**：自解析目录与簇链，插卡即用，数量自适应。
2. **2 MB 双缓冲**：960×540 配 3/4 精确抽取铺满 720p，容量画质兼顾。
3. **写通路解耦**：拆开写 FIFO 出队与帧首复位，切图 30 s → 1.3 s。
4. **超时自愈**：21 ms / 3.4 s 两级超时，自动重挂载重读一次。
5. **零带宽 OSD**：菜单坐标实时生成，帧域透明度做淡入淡出。
6. **参数帧同步**：帧首统一提交，避免半屏撕裂。

### 1.6 设计流程

作品按"需求 → 架构 → 编码 → 仿真 → 综合 → 布线 → 上板 → 迭代"八阶段推进。前四阶段在纯软件环境完成，把可仿真的问题消灭在上板之前；后四阶段在工具链与实板间来回，凡上板现象必先复现为可读的数字（数码管编码、波形），再改 RTL，形成"暴露 → 定位 → 补用例 → 修改 → 回归"闭环，共沉淀 25 篇文档与 9 轮迭代。
