# P10 音频输出与电平可视化

> 对应赛题：基础要求 (3) **基础音频输出**、扩展要求 (5) **音频可视化表现**。

## 1. 先说两个把音频"憋死"的 bug

音频模块从 2026-10-24 就在工程里、lint 也一直过，但**板上从来没响过**。
这轮加了单元测试（`sim/tb_audio.v`）一跑，第一个用例就是 `采样率 0 Hz` ——
两个 bug 叠在一起：

| # | 位置 | 错误 | 后果 |
|---|---|---|---|
| ① | 采样节拍累加器 | `smp_acc <= smp_acc[31:0] + 32'd5498;` —— 右边是 **32 位加法**，进位被丢掉，`smp_acc[32]` 永远是 0 | `smp_tick` 一次都不产生 → **完全静音** |
| ② | 增量常数 | `5498` 比正确值小 **1000 倍**（正确是 5,497,558 = 48000×2³²/37.5MHz） | 就算修好进位，采样率也只有 **48 Hz** |

修法：

```verilog
localparam [63:0] SMP_INC = (SAMPLE_HZ * 64'd4294967296) / CLK_HZ;  // 5497558
smp_acc <= {1'b0, smp_acc[31:0]} + SMP_INC[32:0];                   // 33 位加法，进位保留
wire smp_tick = smp_acc[32];
```

现在实测 **48000 Hz**（10 ms 内正好 480 个采样）。

## 2. 音源：从"单音"升级成"带包络的旋律"

常幅单音的包络是一条直线，电平表根本不会动，所以顺便把音源做出动态：

| 项 | 做法 | 代价 |
|---|---|---|
| 基音 | 500 + 图片编号×100 Hz（8 档，换图变调） | 一张 8 项 case |
| 旋律 | 8 步比率 **1, 1.5, 2, 1.25, 1, 1.5, 2, 0.5**（主音/五度/八度/三度） | 全部是移位+加法，不查表不乘 |
| 节拍 | 每 `NOTE_LEN = 6000` 个采样一步 → **8 音符/秒** | 一个 13 位计数器 |
| 包络 | 起音 192 采样线性升到 255，之后每 16 采样降 1 | 比较器 + 移位 |
| 音量 | 菜单第 6 项 0..10 → 增益 0/26/51/…/256（≈ vol/10） | 8×9 乘法器一个 |
| 输出 | 正弦 × 包络 × 音量，24 位 | 16×8 乘法器一个 |

菜单里的**音量项以前是死控件**（`ef_vol` 从 cfg_latch 出来后没接任何地方），
现在真正控制增益了 —— 调到 0 就是静音。

## 3. 电平可视化：32 柱

`rtl/audio/audio_meter.v`：

- 每 **512 个采样**（10.7 ms）把这段时间的**峰值**推进一根柱子，
  32 根构成 **0.34 秒**的滑动历史 → 视觉上"声音在跳"
- 最新一列画在**最右边**（示波器习惯），柱子宽 6 px + 2 px 间隙
- 颜色按高度分三段：底部绿 / 中部黄 / 顶部红（VU 表观感）
- 画在 **x 480..735、y 624..711**：正好在图片区（y 120..599）和菜单面板
  （y 110..609）**下方**，不遮挡任何内容
- 纯比较器 + 32×8 移位寄存器，**不占 BRAM/DSP**

为什么不做真 FFT：FFT 要几百个乘法器加一堆 BRAM；而且本设计的音源
每步只有一个频率，频谱做出来也只有一根柱子。用"包络峰值历史"
既真实反映音量与节奏，又便宜一个数量级。

叠加方式：菜单混合之后**再串一级 alpha_blend**（两者区域不重叠，
放后面保证电平表永远在最上层）。坐标用已对齐到视频的 `xd4/yd4`，组合逻辑，不加流水。

## 5. 上板怎么看

| 现象 | 说明 |
|---|---|
| 显示器喇叭有 8 音符/秒的循环音阶 | 音频通了（`vol` 默认 6 = 60%） |
| 换图后音高整组变高/变低 | 音视频联动（基音跟图片编号） |
| 画面下方出现跳动的彩色柱子 | 电平表（常开，`top_board` 里 `aud_meter_en` 改 0 可关） |
| 菜单第 6 项调音量，声音跟着变大小 | 音量真正生效（0 = 静音，柱子也会变矮） |

## 6. 已知限制

1. **ACR 是按 37.5MHz 硬编码的**（`N=6144, CTS=37500`）。
   若改回 720p60（75MHz 像素时钟），CTS 必须改成 75000，否则音调偏低一倍。
2. 24 位采样只用了满量程的 **1/4**（`sin << 6` 是设计之初的保守值），
   音量 10 时约 -12 dBFS。想更响可以把输出再左移 1~2 位。
3. 不做立体声分离：左右声道同数据（本设计只有一个音源）。
4. 电平表是"包络历史"，不是频谱 —— 理由见 §3。
