# 上板测试指南（康芯 HX4S20 / EG4S20BG256）

> 目标：把「彩条 + 转场 + 亮度 + 字幕 + OSD 菜单」这条输出级链路跑在真实 HDMI 显示器上。
> 现状：**仿真全部通过；TD 工程已生成，尚未在本机跑完综合（批处理模式需要 license/GUI）**。

---

## 1. 一次性准备

| 项 | 说明 |
| --- | --- |
| TD | `E:\TD\bin\td.exe`（V6.2.168116） |
| 下载器 | AL-Link / JTAG，驱动装好 |
| 显示器 | 支持 1280×720@60（VIC 16），HDMI 直连 |
| 工程 | `prj\yuanshen_hdmi.al`（由 `tools/gen_td_prj.py` 生成） |

打开方式：`td.exe` → File → Open Project → 选 `prj\yuanshen_hdmi.al`。

工程里已经包含：

- 16 个源文件（`rtl/**`）+ HDMI 加密核 + PHY；
- `constraints\board.adc`（引脚）、`constraints\board.sdc`（时序）；
- 顶层 `top_board`，器件 `EG4S20BG256`。

如果工程打不开，退回手工建工程：新建 EG4S20BG256 工程 → 按 `tools/gen_td_prj.py` 里的 `SOURCES` 顺序添加文件 → 加两个约束 → 顶层设为 `top_board`。

改代码后可先在本机做语法检查（不综合）：

```bat
sim\lint_board.bat
```

## 2. 编译与下载

1. **综合**：Run Synthesis（`syn_1`）。
2. **布局布线**：Run Physical Design（`phy_1`）。
3. 看两个报告：
   - Area：LUT 应在 1.5k 以内（本设计 ≈1.1k + HDMI 核）；
   - Timing：`clk_ser`（375MHz）的 Setup/Hold slack 必须 ≥ 0。**这是 720p 能否成立的关键**。
4. Generate Bitstream → Download。

> 首次综合若报 `font_rom` 推断失败，把它换成 IP Generator 的 ROM（同一份初始化数据），其余不动。

---

## 3. 按键

板上 4 个键全用上，复位不再占键（PLL 锁定 + 上电计数自动释放）。

| 板上丝印 | FPGA 引脚 | 功能 |
| --- | --- | --- |
| KEY1 | A2 | MENU：开 / 关菜单 |
| KEY3 | B1 | UP：光标上移 |
| KEY4 | B2 | DOWN：光标下移 |
| KEY2 | C1 | OK：改值（长按 500ms 后 10Hz 连发） |

菜单项与操作：

| 项 | 取值 | 现象 |
| --- | --- | --- |
| 切屏效果 | FADE / SLIDE / WIPE / CUT | 每 150 帧自动切换一次测试图 |
| 亮度 | 0–100% | 整屏变暗/变亮，**立即生效** |
| 对比度 | 0–100% | 灰阶压缩/扩展 |
| 缩放模式 | FIT / FILL / STRETCH | 仅参数链路（等缩放器接入） |
| 字幕 | ON / OFF | 底部滚动条出现/消失 |
| 音量 | 0–100% | 仅参数链路（等音频通路） |

## 4. 预期现象（按顺序）

1. 上电约 0.2s 后出现 **8 段彩条**，底部有半透明黑条 + 滚动文字 `NOW PLAYING 01/12  MUSIC FRAME`；
2. 每 150 帧自动做一次转场（默认 FADE）：彩条 ↔ 渐变网格图；
3. 按 KEY1：全屏压暗 3/8，中间出现 560×500 面板，标题「调试菜单」，六行参数；
4. KEY3/KEY4 移动高亮条，KEY2 改值（例如亮度降到 30%，画面立刻变暗）；
5. 再按 KEY1 关闭：遮罩与面板完全消失，**背景继续播放，不黑屏、不闪断**；
6. 数码管显示 `[项][版本][值]`，每次改参数版本号 +1（可用来确认参数确实落盘）。

## 5. 现场可量化的验收项

| 项 | 方法 | 通过标准 |
| --- | --- | --- |
| 分辨率/刷新率 | 显示器 OSD 信息 | 1280×720@60 |
| 像素时钟 | 示波器测 HDMI_CLK_P 差分 | 375MHz ± 100ppm |
| 菜单不中断播放 | 菜单开/关各录 10s，数帧 | 帧率不变（60Hz），无黑帧 |
| 亮度线性 | 菜单 100%→50%→10% | 屏幕照度阶梯下降，无偏色 |
| 字幕不撕裂 | 菜单开时观察滚动文字 | 文字连续，无半行跳变 |
| 按键 | 连按 20 次 | 无丢键、无重键（去抖 20ms） |

## 6. 常见问题

| 现象 | 排查 |
| --- | --- |
| 显示器无信号 | ① 先确认 `pll_lock` 是否拉高（可把 lock 接到 LED/数码管）；② 720p 的 VIC/时序参数是否被核接受；③ DDC 是否被拉低 |
| 有彩条，按键无反应 | 按键低有效接法；`PULLTYPE=PULLUP` 是否生效；先用数码管看 `dbg_item` 是否变化 |
| 画面花/闪 | 375MHz 时序 slack 为负；先把 `phy_1` 的策略调成性能优先，或降档到 1024×768（65/325MHz）验证链路 |
| 菜单位置偏了 | 确认送进 `osd_menu` 的是**活动区坐标**（本工程已减 HSTART/VSTART） |
| 文字是方块 | `font_rom` 初值没加载，检查 `.mif`/ROM IP 的初始化文件路径 |

## 7. 降档方案（如果 720p 过不去）

改 `top_board` 参数即可，不动其它模块：

| 档位 | HACTIVE/VACTIVE | HTOTAL/VTOTAL | 像素/串行 | VIC |
| --- | --- | --- | --- | --- |
| 720p60 | 1280×720 | 1650×750 | 75 / 375MHz | 16 |
| 1024×768@60 | 1024×768 | 1344×806 | 65 / 325MHz | 16（部分显示器按 4:3 识别） |

PLL 的 `FBCLK_DIV` 同步改：720p 用 15，768p 用 13（探针已验证 65.000/325MHz）。
