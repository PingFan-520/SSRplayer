# P26 音乐转单声道 + 旧图残留修复 + 烧录 Flash 准备

> 2026-10-29 00:30

## 1. 两首音乐被"放慢一倍"——因为它们是立体声

`m1.wav / m2.wav` 的头部：

```
PCM / 2ch / 48000Hz / 16bit        （data 前还有一个 LIST 块）
```

而 `wav_player` 的取样逻辑是**每 1/48000 秒从 FIFO 取一个 16bit 字**当采样输出，
也就是它认定文件是"单声道 48kHz 16bit"。立体声一帧是 L、R 两个字，要占两拍：

| | 帧率 | 播放器 1 秒取走 | 实际听到 |
|---|---|---|---|
| 立体声（原始） | 48000 帧/s | 96000 字 = 48000 帧 | **时长 ×2、低八度** |
| 单声道（转换后） | 48000 帧/s | 48000 字 = 48000 帧 | 正常 |

`m1.wav` 25,466,880 帧本该 265s，按立体声喂进去要播 530s —— 正好"慢一倍"。

### 转换

新增 `tools/make_wav_mono.py`（纯 Python，无需 ffmpeg/numpy）：

- L/R 取平均 `(L+R)>>1` 降成单声道（不削顶，也不会像只取 L 那样丢内容）
- 位深 16bit、采样率 48kHz 不动（素材本来就是 48k）
- 重写成规范 44 字节头（去掉 LIST/INFO，解析最简单）
- 输出 8.3 大写名（菜单里显示的就是它）

```
python tools/make_wav_mono.py 图片资源/m1.wav sd960/M1.WAV
python tools/make_wav_mono.py 图片资源/m2.wav sd960/M2.WAV
```

| 文件 | 结果 |
|---|---|
| `M1.WAV` | 25,466,924 字节 / 265.3s / PCM 1ch 48k 16bit |
| `M2.WAV` | 24,217,644 字节 / 252.3s / PCM 1ch 48k 16bit |

卡上把这两个放进根目录即可（`MUS_MAX=6`，最多 6 首）。如果不想再看到旧的
`T1/T2`，把它们删掉；想都留着也能一起播（菜单里按 8.3 名字区分）。

## 2. 旧图残留在新图后面

**根因**：`LD_SHOW` 里有个"省时间"的优化 —— 上一张图铺满整块就跳过清屏：

```verilog
if (last_full) begin          // 上一张铺满 -> 新图会覆盖全部像素
    sc_clr <= 0; clr_ok <= 1; // 跳过 LD_CLEAR
    ld_st  <= LD_ARM;
end
```

这个前提只在"新图也一定铺满"时成立。一旦新图不满屏（缩放档位不是 1:1、
源图偏小、留边），没被覆盖的地方就留着上一张的像素 —— 也就是看到的"残留"。

**修法**：无条件清屏，把 `last_full` 那套整段删掉。

代价可以忽略：写通路改造后（P24 §11：写 FIFO 连续出队），清屏 518400 像素
只需 **约 35ms**（以前要 0.65s，因为写 FIFO 一天只排空一次），
相对 1.3s 的读图可以忽略。

## 3. 烧录到板子内部 Flash（准备）

### 产物

```
prj/yuanshen_hdmi_Runs/phy_1/yuanshen_hdmi.bit      <- 直接烧这个
out/SSRplayer_20261029.bit                          <- 同一份的存档副本
```

### 步骤（TD 图形界面）

1. 板子接好 USB 下载器（OneCable/JTAG），**SD 卡插着**（设计上电要等 SD 初始化）；
2. TD 打开工程 `prj/yuanshen_hdmi.al`；
3. 点工具栏的 **下载 / Download**（不是"生成码流"）；
4. 在弹出的下载窗口里：
   - 文件选 `yuanshen_hdmi.bit`
   - 目标选 **Flash / 内部配置存储**（不要选 SRAM/JTAG 直接运行，那种掉电就丢）
   - 起始地址 `0x000000`，勾选"擦除后写入"；
5. 点 **Run / 下载**，等进度到 100%（约十几秒）；
6. **断电重新上电**，确认不接下载器也能启动；
7. 板上若有 BOOT/MODE 拨码，拨到 **Flash 启动**（不是 JTAG）。

### 上电自检顺序（出问题先看这里）

| 现象 | 先查 |
|---|---|
| 上电全黑、无 HDMI 信号 | 拨码是否在 Flash 档；.bit 是否真写进 Flash（重烧一次看进度） |
| 有信号但黑屏、数码管最后两位不亮 | SD 没插好 / 卡不是 FAT32 |
| 数码管 `EE`/`FF` 开头 | 挂载/扫描错（卡格式或根目录没有 BMP） |
| 图能出但没声音 | 卡根目录没有 `M1.WAV`（或不是单声道 48k 16bit） |

> 注意：`out/*.bit` 与 `prj/**` 都在 `.gitignore` 里，码流不进仓库；
> 需要时按上面第 3 节重新综合/布线生成即可（默认脚本就能布通）。
