# P13 FAT32 目录扫描（2026-10-27）

> 目标：**插一张普通 SD 卡就能用** —— Windows 格式化 FAT32，根目录拷 BMP / WAV，
> 图片张数、曲目数由目录里实际的文件决定，不再需要 `make_sd_image.py` 做自制镜像。

---

## 1. 卡上的组织形式

```
LBA0            MBR（0x55AA + 分区表，类型 0x0B/0x0C/0x06/0x0E/0x04）
  └ 分区起始     BPB（512B/扇区、每簇扇区数、FAT 数、FAT 大小、根目录簇）
      ├ FAT1/FAT2
      └ 数据区   根目录（簇 2 起） + 文件簇链
```

RTL 支持：

| 项 | 说明 |
| --- | --- |
| 分区表 | 有 MBR 走分区；没有 MBR（超级软盘）直接把 LBA0 当 BPB |
| 扇区 | 512B（SD 规范） |
| 簇大小 | 1~128 扇区，必须是 2 的幂（Windows 常见 8/64 扇区都行） |
| 文件名 | 只认 **8.3 短名**（长名自动用 Windows 生成的 `XXXXXX~1.BMP` 别名） |
| 目录 | 只扫根目录，不递归子目录 |
| 过滤 | 属性 0x0F（长名）/0x08（卷标）/0x10（目录）跳过；`0xE5` 删除项跳过；`0x00` 结束 |

---

## 2. 新增/改写的模块（都在 `rtl/sd/sd_bmp_reader.v` 里）

> TD 命令行不会重新读取 `.al` 里新增的源文件条目，所以新模块并进已有文件。

| 模块 | 作用 |
| --- | --- |
| `fat_mnt` | 读 MBR → 分区 LBA → BPB，算出 `fat_lba / data_lba / spc_log2 / root_clus` |
| `fat_scan` | 遍历根目录簇链，把 BMP/WAV 写进文件表，统计张数 |
| `fat_tbl` | 1KB 文件表：64 条 × 16B（起始簇 4B + 大小 4B + 8.3 名字 8B）；图片读器和音频播放器共用，音乐优先 |
| `sd_bmp_reader` | 按簇链读一张 BMP：每簇读 `spc` 个扇区，簇末再读 1 个 FAT 扇区取下一簇 |

文件表记录分配：`0..55` 图片，`56..61` 音乐。

---

## 3. 关键实现细节（都是踩过的坑）

1. **请求必须在 busy 上升时撤销**
   `rd_start_en` 如果保持到收完 512 字节，仲裁器在 busy 落下后会把它当成**新请求**再授权一次，
   于是一次读变成两次（日志里表现为同一个扇区被读两遍、后续请求全被堵住）。
   挂载、扫描、图片、音频四个客户端都改成"看到 busy 立刻撤"。

2. **FAT 扇区的字节不能混进文件流**
   `sd_bmp_reader` 用 `data_sector` 标志区分"文件数据扇区"和"FAT 扇区"，
   只有前者才输出 `byte_valid`。否则每跨一个簇就会往 BMP 流里插 512 字节垃圾
   （现象：每 4KB 之后全错）。

3. **BRAM 读延迟**
   `fat_tbl` 的读出是"地址 → 等一拍 → 取数 → 右移拼接"三相位，
   拼完 `byte k` 正好落在 `data[8k +: 8]`（左移拼接会得到字节倒序）。

4. **扇区末尾的字段要延后一拍判断**
   目录项的最后一个字节（大小高字节）、FAT 表的第 4 个字节、MBR 的 `0xAA`
   都在"本拍才落盘"，所以项结束/FAT 结束都用 `ev/fav` 标志延后一拍评估；
   MBR 签名直接看 `byte_d`。

5. **扫到文件表写完再开始放图**
   `wb_busy` 单缓冲写表，32 字节目录项 ≈ 256 拍，写 16 字节只要 16 拍，来得及。

## 4. 顶层行为变化

- 上电：SD 初始化 → `fat_mnt` → `fat_scan` → 才开始轮播；
- `IMG_NUM` 参数删除，`img_idx` 在 `img_total`（实际张数，≤56）内回绕；
- 菜单"音乐列表"的曲目数来自 `mus_total`（≤6），字幕显示 FAT 里的 8.3 歌名；
- 没有可用图片时，底部条显示红色 **NO IMAGE**，数码管显示 `F<err>`；
- 7 段数码管：正常时高两位是图片张数，低两位是 `{ld_st, sd_ready}`。

## 6. 上板步骤

1. 卡格式化成 **FAT32**（≤32GB 的卡 Windows 默认就是 FAT32；64GB 以上需要工具）；
2. 根目录拷 `*.BMP`（24bit 未压缩，最长边 ≤4096）和 `*.WAV`（16bit 单声道 48kHz）；
   `python tools/prepare_media.py` 可以批量转格式；
3. 文件名建议用短名（如 `T1.WAV`、`IMG1.BMP`）——长名会显示成 8.3 别名；
4. 上电后数码管高两位显示图片张数；没图会显示 `NO IMAGE`。

> `tools/make_sd_image.py`（自制裸镜像）已废弃，只保留作历史参考；
> `tools/make_fat32_image.py` 只用于生成仿真用的测试卡。
