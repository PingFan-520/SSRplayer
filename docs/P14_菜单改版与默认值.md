# P14 菜单改版与上电默认值

> 日期：2026-10-27
> 涉及文件：`rtl/ui/osd_menu.v`、`rtl/ui/cfg_latch.v`、`sim/tb_osd_demo.v`
> 目的：把"图片轮播 / 转场"收进二级菜单，改掉上电默认值（音乐 OFF、字幕 ON、频谱 OFF）

---

## 1. 三页结构

| 页 | 标题 | 内容 | 进入方式 |
|---|---|---|---|
| 0 | 调试菜单 | `IMG >` / 亮度 / 对比度 / 缩放模式 / 音量 / VU / SUB（7 行） | KEY4 打开 |
| 1 | MUS | OFF / GEN / T1..Tn（n = 卡上 WAV 数，最多 6） | 非菜单态按 KEY3 |
| 2 | IMG | AUT（ON/OFF）/ 切屏效果（FADE/SLIDE/WIPE/CUT） | 设置页第 0 行按 KEY3 |

- **AUT 与转场原来各占一行，现在合并进 `IMG` 子菜单**；设置页由 8 行降到 7 行
- 子菜单里：`AUT` 按 KEY3 直接翻转；`切屏效果` 按 KEY3 循环切换
- KEY4 在任何页都是**一次按键直接关闭**（不要求先返回父页），再次打开回到设置页首行

### 面板尺寸按页变化（都垂直居中）

| 页 | 顶部 y | 高度 | 说明 |
|---|---|---|---|
| 0 | 62 | 596 | 7 行 × 64 + 标题 + 提示 |
| 1 | 30 | 660 | 最多 8 行（OFF/GEN + 6 首） |
| 2 | 230 | 260 | 只有 2 行，做成紧凑小面板 |

行区上限也按页收窄（`row_end`）：二级页 208，设置页 528，音乐页 592 —— 否则提示行会被行区覆盖（实测二级页只显示 `MENU EXI`）。

## 2. 上电默认值

| 项 | 旧 | 新 | 说明 |
|---|---|---|---|
| 音乐（`v_mus`） | 1 = GEN | **0 = OFF** | 上电不再放内置音阶；`tone_gen.mute = (mus != 1)` 真正静音 |
| 字幕（`v_sub`） | 1 | 1 | 保持开启，默认就能看到滚动条 |
| 频谱（`v_meter`） | 1 | **0** | 上电不显示彩条 |
| 轮播（`v_auto`） | 0 | 0 | 上电不自动转场 |
| 转场（`v_trans`） | 0 = FADE | 0 | 不变 |

`cfg_latch`（帧首提交的影子寄存器）复位值同步改成 `mus=0 / meter=0 / auto=0`，否则上电头一帧会用旧值。

配套改动：音乐 OFF 时字幕文案不再是 `NOW PLAYING <空名字>`，而是 `MUSIC PHOTO FRAME`；选中曲目后自动变成 `NOW PLAYING <8.3 名字> MUSIC FRAME`。

## 3. 顺带修掉的三个渲染 bug

### 3.1 字幕字符索引少了 1 位（老 bug）

```verilog
// 旧：sub_tx[8:5] 只有 4 位 -> 只能索引 16 个字
g_sub(sub_tx[8:5], mus_name)
```

- 后果 1：`"MUSIC PHOTO FRAME"` 的第 17 个字（E）永远显示不出来，文案变成 `MUSIC PHOTO FRAM`
- 后果 2：播放态文案 33 个字只显示前 16 个，`MUSIC FRAME` 从来没出现过
- 后果 3：16 字 = 512px 的重复周期，与滚动长度对不上，看上去"紧挨着重复"

修法：索引改 `sub_tx[10:5]`（6 位，64 字 = 2048px），`g_sub` 入参改 6 位，播放态文案压到正好 32 字，滚动长度固定 `SUB_LEN = 2048`。索引取模周期和回卷长度一致，滚动完全连续。

### 3.2 翻页时面板被撕成两半

按键可能落在帧中间：上半帧用旧 `page`（例如 660 高的设置页），下半帧用新 `page`（260 高的子菜单），实拍就是一帧撕裂。

修法：加 **帧首渲染快照** —— `r_open / r_page / r_item` 只在 `frame_start`（x==0 && y==0）更新，整帧渲染只用快照。代价是菜单显示比按键晚 ≤1 帧（33ms）。

### 3.3 音乐列表空行残留 "T"

`g_label` 原来只对数字位做了范围判断，`T` 无条件画。曲目数 3 时，第 5~7 行会剩下孤零零的 `T`。改成整行判断，空行全留白。
