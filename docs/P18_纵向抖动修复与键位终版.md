# P18 纵向抖动修复 + 键位终版

> 2026-10-27 · 上板反馈：整幅画面上下轻微跳动/错行；默认态按切换键无反应

## 1. 键位（按板上丝印，已确认）

用户实测确认：`A2=上  B2=下  B1=菜单  C1=列表`，即：

| 丝印 | 引脚 | 菜单关闭 | 菜单打开 |
|---|---|---|---|
| **KEY1** | A2 | 上一张 | 光标上移 |
| **KEY2** | C1 | 打开**音乐列表** | 关闭（一次退出） |
| **KEY3** | B1 | 打开**功能菜单** | 确认 / 进入 / 改值 |
| **KEY4** | B2 | 下一张 | 光标下移 |

RTL 里 `key_ctrl.key_in` 的位序是 `{OK, DOWN, UP, LIST}`，所以 top_board 的连接是：

```verilog
.key({key3, key4, key1, key2})   // OK=key3  DOWN=key4  UP=key1  LIST=key2
```

上一版写成了 `{key3, key2, key1, key4}`，把 **KEY4（下）和 KEY2（列表）接反**了：
按"下一张"实际打开音乐列表 → 表现成"按图片切换键没反应"。

## 2. 纵向抖动：读通路静默丢字

### 现象与数据

- 数码管 `3 9 0 8 0 0` → 3 张图 / `ld_st=SHOW` / 挂载完成 / 扫描完成，
  加载状态机是稳的，**不是反复重载**
- 抖的是整幅画面上下轻微跳动/错行 → 只可能是"像素流少了若干个字"

### 机制

`frame_buffer.v` 读通路：

```verilog
wire rstart = ... & (rf_used_r < 12'd2032) & ~rf_full & ...;   // 门限 2032 / 2048
rf_wr <= app_rd_valid & ~wr_win_m & ~rf_full;                   // 满了就静默丢
```

像素侧的纵向位置是**靠数消费了多少字**推出来的（每显示行固定吃掉 480 个字 = 一个源行）。
所以丢掉 N 个字，等于后面所有像素提前 N 个字 → 画面**整体上移 N/480 行**。

门限只留 16 个字余量，而 `rf_used` 是跨时钟同步值、本身滞后若干拍，
再加上在途 4 字 burst，硬件上 SDRAM 刷新/仲裁一挤就会真的冲到 2048 → 丢字。
每帧丢的个数不同 → **每帧上移的行数不同 → 整幅画面上下跳动**。

仿真里为什么看不到：假想 SDRAM 立刻返回数据，同步滞后为 0，峰值永远到不了满。

### 修法

1. **预灌门限 2032 → 1024**（半满）。峰值占用从 2036/2048 降到 **1027/2048**，
   余量从 16 字变成 1021 字（≈94µs 的视频消耗量）。读写带宽本来就差 5 倍以上，不需要顶满。
2. **加丢字计数** `rd_drop_cnt`（只统计 `app_rd_valid & rf_full & ~wr_win_m`，
   写窗口开头那几拍在途数据本来就要丢弃、不影响对齐，不计入），
   接到数码管 **最左两位**：正常必须一直是 `00`。

## 3. 数码管新格式（6 位，左→右）

```
读通路丢字 | 图片张数 | {ld_st, sd_ready} | 挂载状态 | 扫描状态
   00      |    3    |         9         |    0    |    8
```

- 正常：`0 0 3 9 0 8`
- 只要最左两位不是 `00`，就说明还在丢字（抖动没修干净），把这个数报出来即可定位
- 扫描错：`.. F <err> ..`；挂载错：`.. E <err> ..`

## 4. 验证

| 项目 | 结果 |
|---|---|
| `tb_frame_full`（真实 SDRAM 模型 + 逐像素） | SDRAM 259200 字 0 错、显示 921600 像素 0 错 |
| 读 FIFO 峰值占用 | **1027 / 2048**（改前会顶到 2036），`rd_drop = 0` |
| 饥饿 / 写丢字 | 0 / 0 |
| `tb_nav_ctrl` | 27 项断言 PASS（OFF 不切、改档重计时、按键挂起不丢） |
| `tb_osd_demo` | 48 项断言 PASS |
| 全工程编译 | Errors 0 |
| 综合 | LUT 9071 / REG 8577 / BRAM 31 / DSP 28；clk_pix **+3.022ns**、clk_mem −0.174ns |

## 5. 上板看什么

1. 上电：静音、字幕滚动、无频谱、画面**不应再上下跳动**
2. 数码管必须是 `0 0 3 9 0 8`；若最左两位非 0，报数字给我
3. KEY1=上一张、KEY4=下一张；KEY3=功能菜单；KEY2=音乐列表
